## 🎯 About

Are you tired of **manually editing your GitHub profile** or missing out on the amazing features you can add? 😩  
Configuring GitHub actions can also be a hassle, right? Say no more! 💪  

✨ **Profile Readme Generator** helps you create a **beautiful & customizable GitHub profile README** in just minutes.  
No complex setup, no wasted time — just showcase your skills and projects like a pro.

## 🏁 Getting Started

```bash
# Clone the project
git clone https://github.com/maurodesouza/profile-readme-generator

# Enter project folder
cd profile-readme-generator

# Install dependencies
yarn

# Run the project
yarn dev
